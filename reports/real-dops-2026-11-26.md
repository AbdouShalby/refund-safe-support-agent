# Real DOPS runs: 2026-11-26

Contract-parity and adversarial suites run against the real order system (DOPS, Laravel + MySQL 8) on a local Docker stack, seeded with `AgentEvalSeeder` (DOPS commit `22b1477`) before every test case. Agent code: the version in this repository on the report date, which includes the handling of unconfirmed submissions.

Commands (from this repository, with `DOPS_BASE_URL`, `DOPS_SERVICE_TOKEN` and `DOPS_RESET_CMD` set; the reset truncates the order and refund tables, flushes Redis and reseeds):

```bash
pytest tests/parity --real-dops -vv
pytest tests/adversarial --real-dops -vv
```

Adversarial cases without the `real_dops_ok` marker are skipped in this mode by design: they rely on the mock's switches (forced gateway outcomes or a lowered auto-approve limit) or test input validation that never reaches DOPS. They run against the mock in the offline suite.

Earlier runs on 2026-11-19 and 2026-11-22, on the code before that change, gave the same totals (parity 11/11, adversarial 6/6). This file replaces their record.
